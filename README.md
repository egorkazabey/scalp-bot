# Scalp Signals Bot (Bybit + Telegram)

Бот следит за фьючерсами Bybit (USDT), ищет скальперские ситуации, присылает сигналы в Telegram
и ведёт по ним **бумажную торговлю** (виртуальный счёт), чтобы проверить, зарабатывают ли сигналы
с учётом комиссий. Реальных сделок бот не делает, API-ключи биржи не нужны.

## Что ищет

| Сигнал | Логика |
|---|---|
| Отскок от плотности | Цена подошла к крупной заявке с высоким рейтингом доверия. Стоп сразу за плотностью. |
| Пробой | Плотность реально «съели» (исполнено 30%+), цена прошла через неё. Вход в сторону пробоя. |
| Всплеск объёма | Минутный объём в N раз выше среднего за 30 минут и цена сдвинулась. Вход по импульсу. |
| Каскад ликвидаций | За 60 сек ликвидировали много лонгов или шортов. Режим reversal (против) или momentum (по). |

У пробоя и всплеска объёма есть режим «против сигнала» (`breakout_mode fade`, `volume_mode reversal`,
включены по умолчанию): ставка на ложный пробой и откат после импульса. Статистика по ним
считается отдельно от режима «по сигналу», их удобно сравнивать в /stats.

Защита от шума: стоп не ближе `min_sl_pct` (0.35%) от входа, а после стопа по монете бумажные
сделки по ней не открываются `stop_pause_min` минут (30).

**Рейтинг доверия плотности (0-100)** защищает от спуфинга: растёт, если заявка долго живёт,
её частично исполняют, а она стоит, и размер стабилен; падает, если заявка «переезжает» за ценой.

Каждый сигнал записывается, и через 1, 5 и 15 минут бот фиксирует, куда пошла цена.
В /stats видно, какой тип сигнала реально работает, а какой только ест комиссию.

## Установка на VPS (Ubuntu/Debian)

**Важно:** Bybit блокирует IP из некоторых стран (например, США, Великобритания).
Бери VPS в ЕС (Hetzner, Contabo и т.п., Германия/Финляндия/Нидерланды). Хватит самого дешёвого (1 vCPU, 1-2 GB RAM).

1. Создай бота у [@BotFather](https://t.me/BotFather), скопируй токен.
2. Узнай свой Telegram id у [@userinfobot](https://t.me/userinfobot) (необязательно).
3. На сервере:

```bash
sudo apt update && sudo apt install -y python3 python3-venv
sudo useradd -r -m -d /opt/scalp_bot scalpbot
# скопируй папку проекта в /opt/scalp_bot (например, через scp или git)
cd /opt/scalp_bot
sudo -u scalpbot python3 -m venv venv
sudo -u scalpbot venv/bin/pip install -r requirements.txt
sudo -u scalpbot cp .env.example .env
sudo -u scalpbot nano .env          # вставь BOT_TOKEN и OWNER_ID
```

4. Проверка вручную: `sudo -u scalpbot venv/bin/python main.py`, напиши боту /start. Остановить: Ctrl+C.
5. Автозапуск 24/7:

```bash
sudo cp scalpbot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now scalpbot
sudo systemctl status scalpbot      # статус
journalctl -u scalpbot -f           # логи в реальном времени
```

Копирование с компьютера на сервер: `scp -r scalp_bot root@IP_СЕРВЕРА:/opt/` и потом
`sudo chown -R scalpbot:scalpbot /opt/scalp_bot`.

## Обновление

```bash
cd /opt/scalp_bot
sudo -u scalpbot git pull
sudo -u scalpbot venv/bin/pip install -r requirements.txt
sudo systemctl restart scalpbot
```

Настройки и статистика (папка `data/`) при обновлении сохраняются.

## Управление из Telegram

Всё через /menu (кнопки): статус, монеты, типы сигналов, настройки, статистика, сделки, пауза.
Текстом тоже можно:

```
/add SOL PEPE ARB         добавить монеты
/remove PEPE              убрать
/movers 5                 топ-5 роста и топ-5 падения за 24ч
/mix                      свой список + топ по обороту + рост/падение
/auto 20                  топ-20 по обороту
/manual                   вернуться к своему списку
/walls SOL                какие плотности сейчас видит бот и их рейтинг
/set min_wall_usd 500k    изменить параметр для всех монет
/set BTC min_wall_usd 5m  параметр только для BTC (у BTC плотности намного крупнее)
/unset BTC                убрать настройки монеты
/stats  /trades  /signals
/pause  /resume
```

## Режимы монет

| Режим | Что отслеживает |
|---|---|
| manual | только твой список |
| auto | топ по обороту за 24ч (`auto_top_n`) |
| movers | топ роста и топ падения за 24ч (`movers_n` в каждую сторону) |
| mix | твой список + топ по обороту + рост и падение |

В авто-режимах список обновляется каждые `refresh_min` минут (по умолчанию 15), бот пишет,
что добавил и что убрал. Монеты с оборотом меньше `auto_min_turnover` не берутся: там стакан
слишком тонкий и легко двигается. Монета не вылетает из списка, пока держится в топе с запасом
(в пределах двойного топа), чтобы список не дёргался. По монетам с открытыми бумажными сделками
данные идут, даже если их убрали из списка.

## Как бот находит плотность

Плотность это заявка, которая сильно выделяется на фоне соседних уровней стакана:
- в `wall_mult` раз (по умолчанию 4) больше среднего из 10 соседних уровней с каждой стороны;
- не меньше `wall_share_pct`% (по умолчанию 1%) от всех заявок этой стороны в зоне поиска;
- из подходящих берутся только `max_walls_side` самых крупных с каждой стороны.

Так правило одинаково работает и для BTC, и для мелкого альта: заявки маркет-мейкеров у спреда
(много одинаковых крупных уровней подряд) не считаются плотностями, а одиночная крупная стенка считается.
Своя настройка монеты (`/set BTC min_wall_usd 1m`) задаёт абсолютный минимум.

Стакан Bybit отдаёт максимум 1000 уровней (`ob_depth`). У BTC с шагом цены $0.1 это всего около ±0.1%
от цены, поэтому дальние плотности BTC не видны. Сколько стакана видно, показывает `/walls`.

Пороги ликвидаций и минутного объёма подстраиваются под суточный оборот монеты (`auto_scale`).
Монеты с тонким стаканом (меньше `min_book_usd` в пределах 1%) пропускаются: там проскальзывание
съедает прибыль.

## Вход, выход и фильтры

- **Три способа входа на отскоке** (`bounce_entry`): по касанию (рынком, как только цена подошла),
  лимиткой прямо перед плотностью (комиссия мейкера, лучше цена) или после подтверждения
  (плотность выдержала удар, её частично съели, а цена пошла назад). Торгует выбранный способ,
  два других бот проверяет виртуально, и в /analyze видно, какой лучше.
- **Безубыток** (`breakeven`): когда цена прошла `be_trigger` пути к тейку, стоп переносится
  в ноль с учётом комиссий. Виртуально каждый сигнал считается и с безубытком, и без него.
- **Фильтры** по выводам анализа: не торговать монеты с очень глубоким стаканом (`max_depth_usd`),
  монеты, которые почти не двигаются за сутки (`min_coin_move_pct`), и сигналы, где совпало мало
  факторов (`min_confluence`, по умолчанию 2: BTC по пути, всплеск объёма, ликвидации, сильная плотность).
- **Сильный сигнал**: при `strong_conf` (3) и больше совпавших факторах сигнал помечается 💪,
  а бумажная позиция берётся в `strong_size_mult` (1.5) раза больше.
- **Дельта против сделки** (`delta_block`): если за минуту рынок давит против входа сильнее
  `delta_block_lvl` (0.3), сделка не открывается.
- **Запрещённые монеты** (`blocked_coins`, по умолчанию SOXL): список через запятую.
  Отфильтрованные сигналы тоже проверяются виртуально, так что анализ продолжает учиться.

## Новости и режим рынка

- **Пауза на новостях**: бот берёт календарь важных экономических событий (ставка ФРС, инфляция,
  занятость в США) и за 15 минут до и 15 минут после не открывает сделки. Сигналы при этом
  проверяются виртуально. Список событий недели: /news. Настройки: «⚙️ → 📰 Новости и режим рынка».
- **Режим рынка по BTC**: тренд вверх, тренд вниз, боковик, тихо, паника. Записывается к каждому
  сигналу и виден в /status. В /analyze есть группа «Режим рынка», и если какой-то режим в минусе,
  его можно исключить: `/set regime_block паника` (несколько через запятую, `нет` чтобы снять).

## Что ещё смотрят профи

- **Открытый интерес** (по тикерам Bybit): за 5 минут перед сигналом новые деньги заходили в лонги
  или шорты, или позиции закрывались.
- **Фандинг**: сделка вместе с перекошенной толпой или против неё.
- **Лента**: дельта (кто агрессивнее, покупатели или продавцы), поглощение (одна сторона давит,
  а цена стоит) и айсберги (по уровню исполнили в разы больше, чем видно, а заявка стоит).
- **Вынос стопов** (новый тип сигнала): цена прокалывает максимум или минимум суток или 4 часов,
  собирает стопы и быстро возвращается. Вход на возврате, стоп за проколом. Настройки в
  разделе «🎣 Вынос стопов».

Всё это записывается к каждому сигналу, а в /analyze есть группы по каждому признаку.

## Длинные стратегии: тренд и фандинг

Работают рядом со скальпингом на тех же монетах, но держат сделку часами, а стоп ставят по волатильности
(1.5 ATR часовой свечи), поэтому шум не выбивает их так легко.

- **Тренд: откат к средней.** Часовой тренд вверх (EMA50 выше EMA200, цена выше EMA200), цена откатилась
  к EMA20 и 15-минутная свеча закрылась зелёной: LONG. Для тренда вниз зеркально. Не чаще раза в 4 часа на монету.
- **Перекос фандинга.** Фандинг ±0.05% и больше (толпа сильно в одну сторону), а цена за час уже идёт против
  толпы: ставка против неё. Не чаще раза в 8 часов на монету.

Держат до 12 часов. Скальперские фильтры (глубина стакана, движение за сутки, совпадение факторов) к ним
не применяются, новости, режим рынка и запрет монет действуют. Настройки в /settings, раздел
«📈 Тренд и фандинг». В /analyze они идут отдельными строками «Тренд» и «Фандинг», так что через пару дней
видно, работают ли они лучше скальпинга.

## График

Раз в 5 минут бот загружает свечи 15м и 1ч по отслеживаемым монетам и для каждого сигнала записывает:
тренд за 1 и 4 часа, положение цены относительно EMA50 и EMA200 на часовиках, RSI(14) на 15м
и расстояние до максимума и минимума суток. В сообщении о сигнале есть строка «🕯 График».
В /analyze появляются группы «Тренд за 4ч», «Цена и EMA200», «RSI 15м по сделке», «Уровни суток»
(всё считается относительно направления сделки: по тренду или против). Как фильтр график пока
не используется: сначала смотрим по данным, помогает ли он.

## Обучение на своих сигналах

Каждый сигнал бот доводит до стопа, тейка или таймаута **виртуально**, даже если бумажная сделка
не открылась (лимит сделок, пауза). Вместе с результатом записывается обстановка: время, направление
BTC, рейтинг и размер плотности, сила всплеска объёма, изменение монеты за сутки, волатильность,
движение цены до сигнала, глубина стакана.

- `/analyze` (или кнопка «🧠 Анализ»): разбор по группам. Вывод («✅ лучше среднего», «❌ хуже среднего»)
  показывается, только если в группе хотя бы `analyze_min` сигналов и отличие больше случайного.
- Автопауза: если тип сигнала на последних `pause_window` (40) сигналах или монета на последних
  `pause_coin_window` (15) стабильно в минусе, бот перестаёт по ним торговать и уведомлять,
  но продолжает проверять виртуально. Когда результат за время паузы становится плюсовым, пауза
  снимается сама. Снять вручную: `/unpause`.
- После одного проигрыша бот ничего не меняет: одна сделка это шум, выводы только на выборке.

## Первая настройка

- Начни с 5-10 монет и смотри `/walls` по каждой: если плотностей слишком много, подними
  `min_wall_usd` или `wall_mult` для этой монеты, если нет совсем, опусти.
- У BTC и ETH плотности в миллионы долларов, у мелких альтов десятки тысяч, поэтому для них
  лучше ставить свои `min_wall_usd` через `/set МОНЕТА min_wall_usd ...`.
- Всплеск объёма начинает работать через 10 минут после запуска (нужна история).
- Дай боту поработать хотя бы 1-2 недели и смотри /stats. Если средний ход через 5 минут меньше
  ~0.11% (комиссия за вход и выход), тип сигнала в текущем виде не окупается.
